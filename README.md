## AgentFrameworkSkills

Simple third-party library for .NET [MS Agent Framework](https://github.com/microsoft/agent-framework) for integration with [Agent Skills](https://agentskills.io/home)

### What it does

It provides support of Agent Skills in MS Agent Framework.
Agents developed with the Framework can now get static list of skills loaded from:

- Programmatic definitions
- Static files
- Remote GitHub repositories

It offers tool for loading skilled when Agent "thinks" its needed and a middleware which injects list of available skills to the conversation history.

### Getting started

```bash
dotnet add package AgentFrameworkSkills
```

Checkout `Samples` for more information.
